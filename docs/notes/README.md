# Supporting notes

A home for detailed plans, research, meeting notes, and project metadata that would clutter the default context.

Use `<owner>/<task>-<topic>.md`, for example `alex/add-login-plan.md`. Each author owns their files. Give each note a title, owner, date, and related task link; distinguish proposals from agreed decisions. Link it from the task handoff or `docs/plans.md` so it can be found without loading every note.

Keep raw logs, generated files, and disposable scratch work in ignored `.tmp/`. Keep secrets out of both committed notes and shared handoffs.
