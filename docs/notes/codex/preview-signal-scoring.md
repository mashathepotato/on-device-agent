# Conservative preview reading value

Preview numeric generation repeatedly produced zero with the original model; an attempted fixed category mapping was too accepting and was reverted. The current fix retains the original local model for one topic sentence and calculates an explicitly labelled heuristic score from actual headline/snippet signals. Full-article behavior and saved fine-tuned weights remain unchanged. The fine-tuned model is disabled.

The preview score starts at 40. No snippet subtracts 8; a snippet of at least 15 words adds 5. Practical-guide wording in the headline adds 24; actionable snippet terms add 12; warnings/disruptions add 12; specific quantities add 7; explanation/evidence terms add 7; sensational withholding subtracts 26; reaction-oriented wording subtracts 10. Scores are bounded to 0–85 because previews cannot establish full-article value. No publisher-name boost, randomized jitter, or fixed score buckets are used. Different input signals give different estimates; repeated identical inputs stay consistent. These are superficial, uncalibrated reading-value estimates, not model predictions or credibility ratings.

The model's output schema now contains only summary. Numeric output from the model cannot overwrite the heuristic estimate. API metadata identifies `preview-signal-estimate-v1`; summary/cache protocol is `search-preview-summary-v4`, clearing old numeric and category results. The UI still shows only the existing colored score and a sentence.

Validation: 30 Python tests and extension publisher/transport tests pass. Five real API cases scored 44 (supply warning), 51 (50mph weather warning), 32 (routine legal news), 81 (practical energy guide with actionable snippet), and 6 (unsupported sensational secret). These cases verify functionality, not predictive accuracy. Actual Google news cards, including captured snippet context, displayed 51 and 39 after restart; screenshot retained locally in ignored `results/mixed-preview-scores.png`. The original-only service runs from this task worktree at http://127.0.0.1:8765; Chrome remains Original.
